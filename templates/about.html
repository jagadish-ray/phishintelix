About PhishIntelix

An intelligent phishing detection platform that combines machine learning with multi-layer heuristic analysis to protect users from phishing URLs and malicious emails.

📋 What is PhishIntelix?

PhishIntelix is a free, AI-powered phishing detection platform built to help individuals, security researchers, and IT professionals identify malicious URLs and phishing emails in real time.

Phishing attacks account for over 90% of data breaches worldwide. Traditional security tools rely on known blacklists and miss new threats. PhishIntelix solves this by combining a trained machine learning model with 5 layers of URL analysis and 10 layers of email analysis — catching both known and zero-day phishing attacks.

The system performs live checks including SSL certificate verification, WHOIS domain age analysis, typosquatting detection using Levenshtein distance, open redirect detection, and cross-references URLs against VirusTotal (70+ engines) and Google Safe Browsing — all in one scan.

⚙️ How It Works
01

ML Classification

7 URL features extracted and fed into a Decision Tree classifier trained on 20,918 URLs to predict phishing probability.

02

Heuristic Analysis

5 independent rule-based layers check for open redirects, URL shorteners, SSL validity, domain age, and typosquatting.

03

Hybrid Scoring

ML score and heuristic findings are combined using a weighted formula to produce a final risk score with verdict.

04

API Verification

URLs are cross-checked in real time against VirusTotal (70+ AV engines) and Google Safe Browsing database.

🚀 Key Features
🤖

Machine Learning URL Detection

Decision Tree classifier trained on 20,918 URLs, compared against 5 other algorithms for best performance.

🔒

Live SSL & Domain Verification

Real-time SSL certificate check, WHOIS domain age lookup, and homograph attack detection on every scan.

🕵️

Typosquatting Detection

Levenshtein distance algorithm checks domains against 25+ popular brands to catch paypa1.com style attacks.

📧

Email Phishing Scanner

10-layer email analysis covering urgency detection, social engineering, spelling check, hidden links, sender verification, SPF/DKIM/DMARC header analysis, and file upload support (.eml, .msg, .txt, .html).

🌐

VirusTotal + Google Safe Browsing

Every URL is cross-referenced against 70+ antivirus engines and Google's threat intelligence database in real time.

📄

PDF Report Generation

Professional downloadable threat report with full findings, risk score, ML features, and security recommendations.

📋

Scan History

Full audit trail of all URL and email scans with filter, search, and email body viewer.

🔀

Open Redirect & Encoding Detection

Detects 15+ redirect parameters and decodes percent-encoding, double-encoding, and base64 hidden URLs.

🔐

SPF / DKIM / DMARC Header Analysis

Parses raw email headers to verify SPF sender authorisation, DKIM cryptographic signature, and DMARC domain alignment policy. Also detects From vs Return-Path mismatch, Reply-To hijacking, and bulk mailer signatures — all classic email spoofing indicators.
