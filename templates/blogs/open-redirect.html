Open Redirect Attacks Explained

How attackers hide malicious destinations behind trusted domain names using ?redirect= parameters.

📅 2026⏱ 6 min read🎯 Advanced

What Is an Open Redirect?

An open redirect is a vulnerability where a website accepts a user-supplied URL in a parameter and forwards the visitor to that URL without validation. Attackers exploit this to make a malicious link appear to come from a trusted domain.

Real example of an open redirect
Trusted domain: https://accounts.google.com
Attack URL: https://accounts.google.com/logout?continue=http://steal-your-password.xyz

The link starts with accounts.google.com — a real Google domain — so users trust it. But the continue= parameter silently sends them to the attacker's site after the page loads.

Common Redirect Parameter Names

PhishIntelix checks for all of these known redirect parameter names:

?redirect=?url=?next= ?goto=?return=?returnurl= ?target=?dest=?destination= ?forward=?continue=?link= ?out=?rurl=?to=

How Attackers Use Open Redirects for Phishing

Step 1
Attacker finds an open redirect vulnerability on a trusted site (e.g. a real bank or service).
Step 2
Crafts a URL like: https://realbank.com/login?redirect=http://fakebank.xyz
Step 3
Sends this link in a phishing email. The recipient sees "realbank.com" and trusts it.
Step 4
After clicking, the victim is forwarded to fakebank.xyz which looks identical to the real site.
Step 5
Victim enters credentials which go directly to the attacker.

URL Encoding — Hiding in Plain Sight

To bypass basic filters, attackers encode the malicious URL inside the parameter so it doesn't look like a URL at first glance.

Percent encoding example
Normal: ?redirect=http://evil.com/login
Encoded: ?redirect=http%3A%2F%2Fevil.com%2Flogin

Double encoding (bypasses some filters)
?redirect=http%253A%252F%252Fevil.com%252Flogin

Base64 encoded
?redirect=aHR0cDovL2V2aWwuY29tL2xvZ2lu

How to Protect Yourself

✅ Always check the full URL in the address bar after clicking a link — not just the starting domain.

✅ Be suspicious of any URL with ?redirect=, ?url=, or ?next= followed by another URL.

✅ Expand shortened URLs and scan them with PhishIntelix before visiting.

✅ If you land on a login page you didn't navigate to yourself, close the tab immediately.
